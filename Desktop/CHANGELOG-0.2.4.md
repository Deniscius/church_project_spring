# Missanye Desktop 0.2.4

- Les demandes locales et leur curseur de synchronisation sont lus ensemble dans un instantané SQLite cohérent.
- Cette protection s'applique aussi lorsque plusieurs comptes synchronisent le même espace paroissial partagé en parallèle.
- Les améliorations de synchronisation et de cache de la version 0.2.3 sont conservées.
